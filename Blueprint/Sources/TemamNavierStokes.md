# Navier–Stokes Equations: Theory and Numerical Analysis

Roger Temam, *Navier–Stokes Equations: Theory and Numerical Analysis*,
AMS Chelsea Publishing, 2001 reprint.

ISBN 978-0-8218-2737-6. Official publisher record:
https://bookstore.ams.org/chel-343-h/

LeanPDE cites Chapter 1 for solenoidal function spaces and the Stokes
pressure framework, Chapter 2 for the nonlinear convection form, and Chapter
3 for evolution compactness. The book itself is not redistributed by this
repository.
